# DelightfulEats

DelightfulEats is a responsive online grocery store web application built with **React.js**. It provides a user-friendly interface for browsing grocery products, exploring categories, and managing items through a dynamic shopping cart.

## Features

- Responsive design for various devices
- Product category browsing
- Dynamic product listing
- Shopping cart functionality
- Reusable React components
- Interactive and user-friendly interface

## Technologies Used

React.js, JavaScript, HTML5, CSS3, Bootstrap, Node.js
